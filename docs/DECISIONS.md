## D9 · 2026-08-19 · Base model family: Qwen3.5 (0.8B/4B/9B) for all three rungs; GRPO via veRL, not TRL
Rationale: Verified against real `config.json` files per `PLAN.md` §11.2, not model cards or industry roundups (see `PLAN-DAY-01.md` Block 6). Qwen3.5 uses a 3:1 hybrid attention layout — 3 Gated DeltaNet (linear attention) layers per 1 Gated Attention (full attention) layer, confirmed via `layer_types` / `full_attention_interval: 4` in `Qwen/Qwen3.5-{0.8B,4B,9B}-Base`'s configs — versus plain Qwen3's uniform full attention. Three measured advantages: (1) native context is 262,144, well past the 65,536 target, so the YaRN phase (`PLAN.md` §5, days 25–32) is skipped entirely; (2) KV cache at 64K is ~4x smaller than Qwen3's equivalent rung, since only the 1-in-4 full-attention layers scale with context — Qwen3.5-4B needs ~1.1 GB Q8 KV @ 64K vs. Qwen3-4B's ~4.8 GB, and stays comfortable even at its full native 262K (~4.3 GB Q8), where plain Qwen3 would need ~19 GB and blow the 12 GB deployment target (`PLAN.md` §3.4); (3) recall/retrieval at this exact 3:1 ratio is not degraded — a systematic academic study (arXiv:2507.06457) found hybrid recall "approaches or exceeds" the full-attention baseline at 3:1, and production RULER numbers for the architectural predecessor (Qwen3-Next-80B-A3B) beat same- and larger-sized full-attention Qwen3 MoE models at every length ≤256K. One real blocker was found and routed around: TRL's `GRPOTrainer` with vLLM `colocate` mode fails on Qwen3.5 text-only checkpoints (weight-prefix mismatch — `QwenLM/Qwen3.6#64`, mirrored at `vllm-project/vllm#36275`; never fixed on that thread, only stale-bot closed). veRL has a merged, reviewed alternative (`verl-project/verl#5682`, merged 2026-03-30, GRPO+FSDP for Qwen3.5) with a since-merged hardening fix for a sequence-parallelism edge case (`#6660`) — and `PLAN.md` §9 already lists veRL as an equal alternative to TRL, so this is a routing choice, not a new dependency. Going all-Qwen3.5 rather than mixing with Qwen3 keeps one tokenizer across all three rungs, preserving the free speculative-decoding draft (§7.4) and an unconfounded Ablation A6. Rung sizes are 0.8B/4B/9B, not the literal 0.6B/8B named in `PLAN.md` §2 — the closest Qwen3.5 dense sizes exist at 0.8B and 9B, not 0.6B/8B; §2's own sizes are stated with "~", so this is within its intent. Licence: Apache 2.0, confirmed, no blocker.
Revisit if: the veRL Qwen3.5 GRPO path fails an actual smoke test on our cluster (not yet run — do before committing the day-33 GRPO phase); the `FLA` / `causal_conv1d` kernel install fails in our environment; AWQ/GPTQ/GGUF quantization tooling doesn't support the hybrid layers cleanly by day 54; or a newer point release (Qwen3.6/3.8 already exist as of Aug 2026) offers materially better tooling maturity before weights are committed for SFT.
